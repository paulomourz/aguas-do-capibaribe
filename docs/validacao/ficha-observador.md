durante a sessão e passe a limpo em [`resultados/`](resultados/LEIA-ME.md) no mesmo dia.

## Tarefas

Resultado: **S** = sozinho · **A** = com ajuda · **N** = não concluiu.

| Tarefa | Resultado | Tempo (min:s) | Erros | Pedidos de ajuda | O que ele disse ou fez |
|---|---|---|---|---|---|
| T1 Entrar | | | | | |
| T2 Estonagem, verde | | | | | |
| T3 Tingimento, amarelo | | | | | Interpretou o resultado? |
| T4 Amaciamento, corrigir peças, vermelho | | | | | Usou "Voltar e corrigir"? O que faria depois? |
| T5 Achar o lote no histórico | | | | | Usou o filtro? |
| T6 Sem internet *(opcional)* | | | | | |

**Erro** é qualquer ação que desvia do caminho e precisa ser desfeita: tocar no menu errado, digitar um número no
campo errado, confirmar com dado errado.
