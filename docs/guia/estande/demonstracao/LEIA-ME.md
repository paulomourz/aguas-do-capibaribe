# Demonstração do sensor: vídeo e prints

Gravados em 26/11/2026, com o site publicado e o sensor no projeto público do Wokwi, para o slide da demonstração da
feira ProjetAÍ ([roteiro](../../roteiro-apresentacao.md#apresentação-na-feira-projetaí)). O 3º lote crítico seguido
da Estonagem (20,70 L contra a meta de 15 L) abriu o Alerta 3 e mandou o aviso no Telegram.

| Arquivo | O que mostra |
|---|---|
| `demo-iot-sensor-3x.mp4` | **Para o slide.** O lote do sensor contando, em velocidade 3x, até o LED vermelho e o "LOTE CRÍTICO" no monitor serial (38 s, sem som) |
| `demo-iot-sensor.mp4` | O mesmo lote em velocidade normal, de reserva (1 min 53 s, sem som) |
| `03-site-alerta-detalhe.jpg` | **A print principal.** O alerta da Estonagem: 3 lotes acima da meta, desvio médio de +41,5%, com os lotes 72, 73 e 74 do sensor |
| `02-wokwi-terceiro-lote-critico.jpg` | O Wokwi com o LED vermelho aceso e o lote 74 crítico no monitor serial |
| `01-wokwi-lote-critico.jpg` | O Wokwi com um lote crítico anterior |
| `04-site-alertas-lista.jpg` | A lista de alertas com o alerta novo, aberto |
| `05-site-historico-sensor.jpg` | O Histórico com os lotes do "Sensor de vazão (Wokwi)". Use só as 3 primeiras linhas: as de baixo são lotes de teste |

Os vídeos mostram só a simulação e o monitor serial: o código do sketch, com o token do sensor, ficou escondido.
